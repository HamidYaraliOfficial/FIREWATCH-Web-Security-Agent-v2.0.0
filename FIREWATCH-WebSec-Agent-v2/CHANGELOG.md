# Changelog

## 2.0.0 - 2026-10-05

- Expanded FIREWATCH from a rule scanner into a complete web assessment pipeline.
- Added same-origin asset inventory, JavaScript endpoint discovery and metadata discovery.
- Added Playwright browser observation with same-origin network guard.
- Added browser request/cookie/storage inventory.
- Added OpenAPI/Swagger discovery and security-declaration review.
- Added GraphQL discovery and optional read-only introspection.
- Added TLS version/cipher and HTTPS downgrade checks.
- Added CORS arbitrary-origin reflection check.
- Added conservative two-profile authorization review candidates.
- Added progress events, asset inventory, richer reports and live dashboard.
- Added single-service integrated queue worker for easy deployment.
- Added optional standalone worker and ZAP automation-plan adapter.
- Added a local demo target and end-to-end verification.

## 1.0.0 - 2026-10-05

- Initial full-stack FIREWATCH Web Security Agent.
