# FIREWATCH v2.0.0 Release Notes

This release upgrades FIREWATCH into a broader web application security assessment platform.

Validated capabilities include same-origin crawling, asset inventory, deterministic web/security checks, OpenAPI/GraphQL discovery, read-only GraphQL introspection, CORS reflection observation, TLS inspection, Playwright browser discovery, progress events, HTML/JSON reporting, a live dashboard, CLI operation, and an integrated job queue.

The package is deliberately scoped and non-destructive. It is intended for authorized assessment environments only.
